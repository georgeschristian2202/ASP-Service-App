# 📍 Comment Obtenir les Coordonnées GPS Exactes d'ASP Services

## Méthode 1 : Via Google Maps (Recommandé)

1. **Ouvrir Google Maps** : https://www.google.com/maps

2. **Rechercher votre atelier** :
   - Tapez : "Libreville Likouala église Hebron"
   - OU naviguez manuellement vers votre atelier

3. **Cliquer sur votre emplacement exact** sur la carte
   - Faites un **clic droit** sur l'emplacement exact de votre atelier
   - Cliquez sur les coordonnées qui apparaissent (format: `0.xxxxx, 9.xxxxx`)

4. **Les coordonnées sont copiées** dans votre presse-papier
   - Format : `0.4162, 9.4673` (exemple)
   - Premier nombre = Latitude
   - Deuxième nombre = Longitude

5. **Envoyez-moi ces coordonnées** et je vais les intégrer dans le site

## Méthode 3 : Depuis votre smartphone

1. Ouvrir **Google Maps** sur votre téléphone
2. Activer la localisation GPS
3. Se rendre à votre atelier
4. Appuyer longuement sur votre emplacement exact
5. Les coordonnées apparaissent en bas de l'écran

**Envoyez-moi les coordonnées au format :**
```

Longitude: 9.XXXXX
```

**Exemple pour Libreville (approximatif) :**
```
Latitude: 0.4162
Longitude: 9.4673
```

Je vais ensuite les intégrer dans le code pour que la carte affiche **directement et précisément** votre atelier dès le chargement.
