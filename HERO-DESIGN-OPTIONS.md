## 🌟 Option 1: Parallax Background

### Description
Images de vos projets qui défilent en arrière-plan avec effet parallaxe

### Aperçu Visuel
```
┌────────────────────────────────────────┐
│  Header (transparent au début)         │
├────────────────────────────────────────┤
│  [Image projet 1 - floue - couche 1]  │
│    [Image projet 2 - moins floue]     │
│      [Texte principal - net]          │
│        Votre Expert en                │
│        SIGNALÉTIQUE                   │
│                                       │
│        [CTA Button]                   │
│  [Image projet 3 - floue - couche 3]  │
└────────────────────────────────────────┘
```

### Caractéristiques
- ✅ Images de vos réalisations en fond
- ✅ Effet de profondeur (3 couches)
- ✅ Scroll = images bougent à vitesses différentes
- ✅ Overlay sombre avec dégradé

### Inspiration

- Stripe.com
- Figma.com
