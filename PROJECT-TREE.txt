🚀 COMMANDES RAPIDES

Installation :
  cd frontend && npm install

Développement :
  make dev              (avec Make)
  cd frontend && npm run dev    (sans Make)

Docker :
  make docker-up        (avec Make)
  docker-compose up -d  (sans Make)

Documentation :
  cat README.md
  cat GETTING-STARTED.md
  cat ARCHITECTURE.md
  cat COMMANDS.md
